# 建筑平面图模板生成器 · 使用说明

改几个数字和文字，一键生成 A3 建筑平面图（图框 + 140×32 标题栏 + 轴线/墙/柱平面图），输出 DXF + DWG + PDF 三件套。全程本地运行，不调用任何 AI。

## 准备（只做一次）

1. 装 Python（https://www.python.org），安装时勾选 “Add python.exe to PATH”。
2. 装依赖：在本文件夹打开命令行（地址栏输入 `cmd` 回车），运行：
   ```
   pip install ezdxf matplotlib
   ```
3. 装 ODA File Converter（免费，DWG 转换用）：https://www.opendesign.com/guestfiles/oda_file_converter
   不装也能用，只是不会生成 DWG（DXF 和 PDF 照常生成；DXF 也能直接用 CAD 打开再另存为 DWG）。

## 使用

1. 用记事本打开 `params.json`，改参数（见下表），保存。
2. 双击 `运行.bat`（或命令行运行 `python plan_template.py`）。
3. 到 `输出` 文件夹取文件：`<学号+姓名>.dxf / .dwg / .pdf`。

给同学做一份：把 `name`、`student_id`、`date` 改成他的，`basename` 留空即可（文件名自动用他的学号+姓名），重跑一次。

## 参数表

| 参数 | 含义 | 默认 |
|---|---|---|
| `name` / `student_id` | 标题栏姓名、学号；也决定输出文件名 | 戴锦源 / 2025310205 |
| `college` / `class_text` | 标题栏学院、班级文字 | 智能建造学院 / 2025建电2班 |
| `date` | 制图日期，`auto` = 运行当天（格式 YY.MM.DD），也可写死如 `"26.11.27"` | auto |
| `drawing_title` | 图名（图下居中大字） | 建筑平面图 |
| `sheet_total` / `sheet_no` | 标题栏张数字段 | 共1张 / 第1张 |
| `x_spans` | 横向每跨宽度（mm），数组有几项就有几跨，如 `[6000, 4500, 6000]` 是三跨 | [6000] |
| `y_spans` | 纵向每跨进深（mm），同上 | [6000] |
| `wall_thickness` | 墙厚（mm），内外墙线间距 | 240 |
| `column_size` | 柱截面边长（mm），柱画在每个轴线交点 | 400 |
| `scale` | 比例分母（100 = 1:100），标题栏比例和图名自动跟着改 | 100 |
| `center_square_mm` | 平面中心小方块边长（mm），0 = 不画 | 600 |
| `center_lines` | 是否画穿过平面中心的十字线 | true |
| `out_dir` | 输出文件夹（相对本文件夹） | 输出 |
| `basename` | 输出文件名（不含扩展名），空 = 学号+姓名 | 空 |
| `oda_path` | ODAFileConverter 程序路径，空 = 自动查找；自动找不到时把完整路径填这里（反斜杠写双份，如 `"C:\\Program Files\\ODA\\ODAFileConverter 27.10\\ODAFileConverter.exe"`） | 空 |

## 注意

- 跨数变多、跨度变大时平面可能放不进 A3：程序会打印提醒，此时改大 `scale`（如 150、200）或减小跨度。
- 当前版本画的是外墙 + 柱 + 轴线（和已交作业的那张同款）；内墙、门窗洞口暂未参数化，需要时再扩展。
- 文字字体用 SimHei（黑体），Windows 自带；别的系统打开 DXF 时 CAD 会自动替代字体。
